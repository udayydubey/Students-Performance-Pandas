# Students Performance Analysis — Pandas

A beginner-level Pandas project exploring student study habits, attendance, class participation, scores, grades, and derived metrics.

## Dataset

- 1,000,000 rows
- 6 original columns: `student_id`, `weekly_self_study_hours`, `attendance_percentage`, `class_participation`, `total_score`, `grade`

## Analysis Covered

- Dataset shape, head, tail, and columns
- Maximum study hours, attendance, and participation
- Top students by weekly self-study hours
- Score-based `ScoringLevel` classification
- Students with the highest total score
- Count of students scoring 100
- Score efficiency calculation
- Study-hour `Category` classification

## Tools

Python, Pandas, NumPy, Jupyter Notebook

## Project Level

Beginner → Early Intermediate Pandas practice.
